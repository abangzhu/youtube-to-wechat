# 翻译与本地化

用于外语来源、机器中文字幕和译稿核查。先保证原意可核查，再使中文自然。格式、引号、术语拼写和技术内容保护以 [narration-and-formatting.md](narration-and-formatting.md) 为准；本文件只处理语义和翻译选择。

## 1. 分清来源、翻译、分析和文章

原始字幕或原文是证据，不在其上直接润色。保留获取到的文本、来源和定位信息；发现转录疑误时回查音视频、幻灯片或原始文档，在工作笔记记录更正依据。

是否生成完整双语底稿由 [SKILL.md](../SKILL.md) 的交付配置决定；外语来源本身不触发完整双语交付。普通改写保留原始来源和关键原话的原文、译文即可。

需要生成双语底稿时，它用于核对原意。正文信息、否定、条件、数字、说话人变化和不确定性不能省略；普通停顿词可不逐字译出。为恢复字幕中被切碎的句子，可合并相邻片段翻译，但需保留全部原文及其时间戳，说明分组方式。不能将概要写成“完整逐字翻译”。用户要求严格逐行对应时按该要求交付。

结构化笔记可以归并主题，文章可以为读者重排材料，两者都应能回到对应原文。补充研究、原作者判断和编辑推论分开记录；不要在翻译层悄悄修正一个事实错误，让读者以为原文说得正确。

稿型决定保留范围：全译保留约定范围内的信息；教程保留复现细节；解释型公众号可以筛选。参见 [article-structure.md](article-structure.md#1-先确定稿型再筛选素材)。

## 2. 先读上下文，再确定句子含义

翻译一个片段前，找出说话人、实际行动主体、指代对象和讨论范围。`it`、`they`、`this`、`that capability`、`thing` 等泛指词需要结合上下文理解；必要时用确切名词代替代词，但不能补出原文没有的对象。

相同的表面动作可能对应不同含义。例：“重复得更快”表示速度，“重复得更频繁”表示次数或频率；根据原文选择，不能把两者当成随意替换的文风选项。动作的目的只有在原文明确或上下文足以支持时才能补出。“屏幕上开着工具”本身不足以证明正在用它分析数据。

遇到疑似 ASR 错误，先回查关键名称、数字、否定词和技术词。无法确认时保留不确定性，避免让后续文章依赖它；不要依靠“这句话应该是这个意思”将猜测写成事实。

## 3. 翻译必须保留的语义

| 要素 | 常见失真 | 核查方式 |
|---|---|---|
| 主体与对象 | 团队判断变成平台立场；A 服务 B 译成 B 服务 A | 明确谁对谁做什么，保持归属 |
| 量词与范围 | some 变 all；未必捕获全部价值变成无法捕获价值 | 检查“部分、全部、仅、至少、最多”等词修饰什么 |
| 可能性与强度 | may 变必然；较少变没有；有希望变已经完成 | 保留概率、时间和完成状态 |
| 因果与条件 | 同时发生变成因果；在某配置下有效变成普遍有效 | 检查原文是否真正给出了因果或条件 |
| 比较口径 | 次数当比率；不同分母直接比较；比较方案写成对照实验 | 核对样本、分母、单位、基线、指标定义 |
| 人物态度 | 选择 B 变成放弃 A；承认、拒绝、故意等态度被添加 | 只保留有证据的态度和行动历史 |

`2/16` 变为 `3/48`，通过数量增加，通过率却由 12.5% 变为 6.25%。不能写成通过率提高，也不能仅凭这两个小样本断言质量稳定下降。对照案例见 [案例库](examples/editorial-cases.md#案例二数量比率和比较口径)。

## 4. 自然中文是选择，不是替换公式

以下是诊断方向，不是见词就改的规则。

- **长句与定语**：若读者要读到句末才能找出主体，可拆句或调整顺序；拆分后仍要保留条件、指代和因果。没有统一字数阈值。
- **名词化**：“进行结果验证”常可写成“验证结果”；但“结果验证”作为模块名称或讨论对象时可以保留。
- **被动句**：主动和被动都可自然。若重点是受影响的对象，“数据被删除”比隐去删除状态更清楚；未知施事不能为改成主动句而杜撰。
- **连接词**：删掉机械重复的连接，但保留读者辨认条件、因果、转折所需的关系。中文不等于永远省略连接词。
- **代词**：同一主体清楚时可省略；多个主体交替时补回名称。不要机械禁用“它”，也不要要求每句重复全名。
- **习语**：结合语境意译。`move the needle` 可指“产生实际影响”，不必升级为“产生显著影响”；原文没有统计检验时尤其不能引入统计显著性。
- **程度词与语气**：空泛加强词可删；表达真实不确定性、近似、比较或反预期时保留。`almost`、`roughly`、`not necessarily` 不因文风偏好消失。

不设唯一正确措辞，例如“让问题更复杂”和“让问题变得更复杂”都可能自然。判断依据是原意、上下文和可读性，而不是是否匹配某个历史改句。

## 5. 数字、时间与技术材料

数值换算要保留单位和精度。英语百万可换成中文万，但不能因追求整齐而改变数量级。百分比与百分点区分，成本对比写明比较的是单次运行、整个实验还是官方定价。

相对时间以录制、发表或事件时间为基准，不能自动按今天解释。能确认时改成绝对时间；不能确认时写“在录制时”或保留有限描述。原文的 `today` 可能指“目前”，不一定指某个自然日。

官方文档和教程应保持版本、参数、默认值及示例条件。不能只因新版存在就替换原文描述；更新信息应标明时间和差异。原代码与中文说明分开，具体要求见[技术内容规范](narration-and-formatting.md#术语与技术内容)。

## 6. 核查与停止条件

对影响主线的段落回看原文，逐项核对主体、断言、条件、数字和归属。对可疑译句可试着简述回原语言，检查是否多出了肯定、因果或范围；回译只作辅助，不能代替来源核对。

机械搜索适合定位数字、重复术语和疑似错误，不判断自然语言是否合格。关键含义准确、语义关系清楚、术语一致且阅读顺畅后结束。不要为了证明做过翻译润色而改掉本来准确的表达。
