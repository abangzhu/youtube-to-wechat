# 文风诊断提示

文件名保留兼容既有引用。本文件提供需要结合语境判断的提示，**不是禁词表，也不要求扫描零命中**。适用于普通中文叙述；引语、原文标题、代码、UI 文案和技术术语按 [narration-and-formatting.md](narration-and-formatting.md) 处理。

事实、观点归属、条件和证据强度优先于文风。遇到疑似套话，先问它是否提供信息、表达必要关系或保留原意，再决定删除、改写或保留。

## 常见信号与判断边界

| 信号 | 可能的问题 | 何时保留 |
|---|---|---|
| “值得注意的是”“关键在于”“有趣的是”反复开场 | 先评价后给事实，增加无内容铺垫 | 用于确有必要的重点转移，且删掉会弱化层次时 |
| “真正”“其实”“显然”“毫无疑问”密集出现 | 用语气代替证据，或把推测说得过满 | 表达有依据的反预期、真实对比或忠实引语时 |
| “可能”“近似”“通常”“在这次实验中” | 有时只是模糊表达，但往往是关键限定 | 只要反映证据强度或适用范围，就保留，不为果断语气删除 |
| “不是 X，而是 Y”反复出现 | 制造没有实际分歧的二元对立 | 确实需要排除一种解释、区分概念或修正误解时 |
| “颠覆”“碾压”“崩塌”“彻底改变” | 超出证据的夸张或戏剧化 | 来源充分、描述恰当，或“崩溃”等词有明确技术含义时 |
| “飞轮”“闭环”“范式”“赋能” | 抽象词遮住具体机制 | 技术概念已定义，且能准确描述机制时；不要统一换成更含混词 |
| “首先、其次、最后”机械串联 | 用序号掩盖论点之间没有关系 | 真有顺序、步骤或平行项，能帮助读者导航时 |
| “他停顿了一下”“现场响起掌声” | 对当前阅读目标无用的舞台信息 | 事件、态度变化或互动本身是讨论对象时 |
| “你一定会”“看完就能”“所有人都” | 未兑现的承诺或未经证实的群体判断 | 有明确依据且范围准确；否则改成具体问题或有条件的说明 |

不要把一种写法固定替换成另一种。“更像”可能表示近似，“同时”可能表示时间关系，“被”可以准确表达受影响状态；替换前必须理解意思。冒号、破折号、引号等格式判断统一见[格式规范](narration-and-formatting.md#标点与引号)。

## 有效的改写方向

用具体对象和动作解释抽象判断，但只使用材料中已有或明确注明的补充信息。用证据支撑强调，避免给人物补情绪或给普通结果加转折剧情。删除重复铺垫时，保留必要归属和逻辑连接。

例如，“这段演示给出了一个非常重要的启示”如果只是预告，可直接写演示支持的结论；但“讲者认为这个方法有望降低成本”中的“讲者认为”和“有望”可能都不能删。

比喻、幽默和口语可以保留，只要帮助理解且不歪曲事实。文章不必每句都像技术说明，也不必为了“有人味”编造个人经历或读者心理。

## 如何使用扫描结果

搜索只定位值得复读的句子。按语义判断后，结果可以是修复、保留或不适用；无需向用户逐条报告，也不需要每轮审查都找出新问题。

完成标准是空泛重复和重要理解障碍已处理，事实与限定保持完整，全文语气一致。若剩余提示都有合理用途，就结束文风检查。关键语义问题见 [sentence-level-errors.md](sentence-level-errors.md)，完整验收见 [self-review.md](self-review.md)。
