# 运行环境工具适配

本技能描述能力与产物，不假定统一的 MCP 命名或固定工具版本。执行前查看当前可用工具、schema 和运行环境说明；以下代码片段是可选实现，只有对应能力可用时才运行。

## 文件与网页

- 使用当前环境的文件读取、shell 或文档工具。PDF 可先抽取文本，再实际查看关键图表页；扫描件需要 OCR，不能把空文本当成空文档。
- 网页读取需要正文、标题、段落、示例和代码。若服务只返回摘要，改用允许的浏览器读取方式并检查分页、折叠内容和虚拟列表；`document.body.innerText` 也可能包含导航噪声或漏掉未加载内容。
- 读取后验证内容覆盖范围，保留原始来源。字幕获取与状态见 [youtube-transcript-fallback.md](youtube-transcript-fallback.md)。

## 浏览器与图片

- 优先当前已提供的浏览器/截图工具；按其文档选择页面、定位元素、seek 和截图。Chrome DevTools、Playwright、原生浏览器代理的参数不同，不复制不存在的工具名，也不向 schema 外硬塞参数。
- 工具允许元素截图时优先只截目标区域；否则用受支持的截图加裁切。每次变更页面、窗口大小或 DOM 后重新定位。具体流程和素材契约见 [visual-capture.md](visual-capture.md)。
- HTML 卡片可以用当前浏览器渲染，也可以用已安装的 Chromium CLI；没有浏览器不等于没有来源图片。按可用能力选择来源图或保留明确的待完成项，不能声称已出图。
- 本地路径、截图返回值和工具允许写入的目录各自可能不同。按工具支持的文件输出或下载方式保存素材；不通过转码、换路径或调用其他 API 绕过拒绝的权限。
- 截图和生成图片都需要实际看图。文件大小、哈希和分辨率用于文件检查，不能证明图中的内容正确。

## 外部服务与权限

- 网络受限时先检查本地材料与当前可用连接器，遵守运行环境的授权机制。不得绕过登录、付费、文件权限或工具 schema 限制。
- 服务失败不意味着源内容不存在。临时错误可有限重试；权限或能力缺失需换受支持的路径。记录当时条件，恢复后允许重新探测，见来源回退指南。
- 上传/发布前探测连接器当前支持的块类型、图片方式和限制；不要把历史“能透传”或“不能上传”的经验当成现状。用户已授权发布时，在能力允许范围内执行，不增加重复批准步骤。

## 用户选择与交付状态

- 按主流程保留用户先确认标题与正文、再生成最终封面与摘要图的偏好；已有明确选择直接复用。只有缺少会影响结果的输入时才询问，不重新询问已授权的常规动作。
- 使用当前环境允许的提问方式；结构化提问工具不可用时用简短自然语言，不调用当前模式禁止的工具。
- 工具故障只阻塞依赖该能力的环节。继续可完成的正文、核验、素材清单等工作；最终说明已经完成、尚未完成及原因，不能把图片占位、未上传文件或未确认页面算作发布成功。
